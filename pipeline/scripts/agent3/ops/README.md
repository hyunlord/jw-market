# Agent3 operational recovery artifacts

These files preserve the exact scripts and target set used by the audited
one-time Agent3 recovery and strategic-strength runs. They are not scheduled
entry points. Production jobs must continue to use the canonical runners under
`pipeline/scripts/agent3/` and must keep the workflow revision/mode assertions.

The fixed revision and target list are historical evidence. Do not reuse them
for a later mart epoch without creating a new, reviewed worklist.
