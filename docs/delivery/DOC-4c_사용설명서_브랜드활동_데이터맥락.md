## 1. 브랜드활동 데이터가 만들어지는 과정 (유저 관점)

`[기고 필요]` 뉴스 크롤 → 이벤트 추출 → 토픽/브랜드 매칭 → 대시보드 표출까지를 유저가 이해할 수준으로 서술. 근거: 파이프라인 코드(상세는 DOC-1b 참조 링크). "이 숫자는 어디서 오나"에 답하도록.

## 2. 갱신 주기 · "최근 N일"의 의미

`[기고 필요]` 데이터가 며칠 주기로 갱신되는지(크롤 CronJob 스케줄 근거), 화면의 "최근 N일"/기간 표기가 정확히 무엇을 세는지. 근거: 실측 스케줄·집계 윈도우 코드 `파일:줄`.

## 3. 데이터 없음 사유 (원천 0 vs 미수집)

`[기고 필요]` 브랜드/토픽이 비어 보일 때, ① 실제 원천 이벤트가 0인 경우와 ② 아직 수집·매칭 안 된 경우를 어떻게 구분하는지. 근거: 매칭 로직·top-N 절삭 등 실코드(예: 서빙이 읽는 집계 커버리지).

## 4. 유저가 오해하기 쉬운 지점

`[기고 필요]` 예: 브랜드↔토픽 매칭 방식, 상위 N 절삭으로 일부만 보이는 것, 활동지표가 판매가 아닌 것 등. 실동작 기준으로만.
