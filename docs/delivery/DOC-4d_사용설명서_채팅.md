## 1. 채팅 사용법

- 포탈 채팅 화면에서 **질문을 입력**하면 답변이 마크다운(본문 + 필요 시 표·차트 + 출처)으로 표시된다. 응답 형식: 본문 `text`, 차트 `charts`, 출처 `sources`, 파일 그라운딩 시 `file_sources`(DOC-3b §1.3).
- 스트리밍 화면은 단계 진행(step)→본문(delta)→표(markdown_block)→차트→타이밍→완료 순으로 점진 표시된다(SSE, DOC-3b §1.3).
- **동시 사용자가 많으면** "현재 사용자가 많습니다. 잠시 후 다시 시도해주세요."가 표시될 수 있다(동시 처리 상한, 최대 대기 약 10초 후 안내; DOC-3b §3.1). 잠시 후 재시도하면 된다.
- 화면 진입 경로·버튼·대화 목록 UI 등 포탈 화면 세부: `[확인 필요]`(SI 포탈 프론트 소관). `[화면: 포탈 채팅 입력/응답 화면]`

## 2. 질문 유형별 안내 (잘 되는 것)

현행 라우팅이 실제로 처리하는 유형:

- **시장/브랜드 지표 조회**: 특정 브랜드·시장의 지표를 물으면 시장분석 데이터에 근거해 답한다. 답변에는 출처·표·차트가 붙는다. (라우팅·근거 조립: DOC-1c §1)
- **뉴스/이슈 기반 심층 설명("심층분석")**: 브랜드 관련 뉴스·이슈를 큐레이션 코퍼스에서 찾아 설명한다. 별도 버튼/모드가 아니라 질문 내용으로 발동한다(DOC-3b §1.1).
- **업로드 파일에 대한 질문**: 파일을 올린 뒤 그 내용을 물으면 파일 근거로 답한다(§4).
- **외부 근거가 필요한 질문(임상시험·허가·FDA·HIRA)**: 외부 조회로 보강하되, 외부 결과의 취급은 §3의 한계를 따른다.

> 질문은 **한 번에 완결된 문장**으로 쓰는 것을 권장한다(사유: §3의 멀티턴 한계).

## 3. 한계 (대답 못 하는 유형 · 주의) — 현행 실동작 기준

- **멀티턴 문맥 승계 — 미지원.** 이전 질문/답변은 저장은 되지만 다음 답변의 근거로 **자동 반영되지 않는다**(턴이 프롬프트에 주입되지 않음; `conversation.py` turns는 기록만). 따라서 "그럼 그건?"처럼 앞 답변에 의존하는 후속 질문은 의도대로 동작하지 않을 수 있다 → **각 질문을 완전한 문장으로**. (예외: 직전 턴이 "시장 기준 선택" 요청이면 그 선택만 이어짐.)
- **웹 검색 결과 = 미검증.** 실시간 웹 결과는 "웹 검색 결과(미검증)"로 **출처만 분리 표시**되고 내부 확정 근거로 승격되지 않는다(`client.py:730-731`). 웹발 수치는 참고로만.
- **외부 API(임상시험·허가·FDA·HIRA) 의존.** 해당 근거가 필요한 질문은 외부 조회에 의존하며, 실패 시 오류를 감추지 않고 부분 근거로 처리한다(임상시험은 실패 시 fail-closed로 해당 근거 없이 진행; DOC-3b §3.2). 외부 지연 시 답변이 느려지거나 그 근거가 빠질 수 있다.
- **미지원 브랜드/범위.** 시장분석 데이터에 없는 브랜드·범위는 답할 수 없다(근거 부재 시 확정 fact만 조립하는 폴백; DOC-3b §3). 없는 것을 지어내지 않는다.
- **정형 통계 파일 직접 첨부 질답 제한.** 채팅에 `.csv/.xlsx/.parquet` 등 정형 파일을 **직접 첨부**하는 경로는 거부된다("정형 통계 업로드는 거부됩니다", `rag/local_rag.py:28`). 정형 데이터는 시장분석 화면/데이터 인입(DOC-4a·4b) 경로를 쓴다. (파일 질답은 §4 경로.)

## 4. 파일 업로드 질답 사용법

- **방법**: 포탈에서 파일을 업로드한 뒤 그 파일에 대해 질문하면, 채팅이 파일 검색 결과를 근거로 답한다. 파일 근거가 쓰였으면 답변에 `file_sources`(파일명)가 표시된다.
- **처리 경로**: 파일 파싱·색인은 채팅 서비스가 직접 하지 않고 **wf301 브리지(`code-serving-235`)/전처리기**가 담당한다(`file_search_client.py:18-68`). 채팅은 그 결과 컨텍스트만 사용한다.
- **준비 시간(대형 파일 주의)**: 업로드 직후에는 색인이 끝나지 않았을 수 있다. 채팅의 파일 검색은 짧은 타임아웃(기본 3초, `file_search_client.py:29`)으로 조회하며, 준비 전이면 **파일 없이 답이 진행**된다. → 대형 파일은 잠시 기다린 뒤 질문하고, 파일 근거가 보이지 않으면 재질문한다.
- **지원 형식·범위**: 실제 지원 형식·형식별 동작은 전처리기(235) 소관이며 채팅 코드에는 형식 목록이 없다 → **[확인 필요]**(235/전처리기 문서). 내부 검증용 형식 매트릭스가 있더라도 그것이 곧 "전부 지원"을 뜻하지 않으므로 단정하지 않는다.
- **질문 없이 파일만** 올리면 "파일 저장 완료" 류 확인 답변이 온다(`sources=["file_upload"]`, app.py:476-492). 이후 질문하면 그 파일 맥락으로 답한다.
